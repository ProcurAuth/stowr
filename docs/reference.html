Rules

  • An unknown block, an unknown attribute or a duplicate attribute stops the start.
  • A value that is not in its range stops the start. The error gives the key and the line.
  • A key without a value in the file has its default value. A key with (required) must have a value.
  • A file needs one access block. The block has mode authzen or mode open.
  • A file needs one bucket block or one volume block at least. A bucket block needs an auth block.
  • A duration is one whole number and one unit: ms, s, m or h. For example: 500ms, 30s, 5m, 1h. A sign, a fraction, a space or two units (1m30s) stops the start.
  • stowr print-config -c <file> checks the file, writes the value of each key and its source, and exits with status 0. The source is file, env:<VAR>, file:<path> or default. The output hides each secret.
  • At start, the server writes the same values in its log.

Values from the environment or from a file

The column Forms gives the forms of each key:

  • value: <name> = "...". The value is in the file.
  • _env: <name>_env = "VAR". The value is in the environment variable VAR.
  • _file: <name>_file = "/path". The value is the content of the file, without the last line end. A relative path starts at the directory of the configuration file.

Give one form only. Two forms stop the start. A variable that does not exist, an empty value, or a file that the server cannot read stops the start. The server reads each variable and each file one time, at start. The server reads no environment variable that the file does not name.

A secret key has yes in the column Secret. A secret accepts only _env and _file: a secret in clear text in the file stops the start. The output of print-config and the log show <hidden> for it.

No change of a value

The value in the file is the value that applies. The server does not remove spaces, does not change the case, and does not add or remove a /. A value that does not fit stops the start. The error gives the key, the expected form and the value.

An error about a secret does not show the value. A text value must not be empty. It must not have a space at the start or at the end. To use the default of a key, remove the key.
